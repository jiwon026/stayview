# 🏨 Stay-View — 호텔 리뷰 요약 기반 숙소 탐색 대시보드

Booking.com 리뷰를 수집·요약해 호텔을 지도와 항목별 점수로 탐색하는 Streamlit 앱입니다.
숙소마다 긍정/부정 요약문과 6개 항목 감성 점수를 보여주고, 지도에서 위치를 확인할 수 있습니다.

**배포된 앱 → <https://stayview-11.streamlit.app/>**

> 팀 프로젝트로 진행했으며, 이 저장소는 그중 한 버전입니다.

## 개발 목적

- 호텔을 고를 때 필요한 정보를 한 화면에서 시각적으로 제공
- 긴 리뷰를 긍정/부정 요약으로 압축해 의사결정을 돕기
- 지도 기반 탐색으로 위치 감각을 직관적으로 전달

## 주요 기능

- **지역 → 호텔 2단계 선택** — 9개 지역, 호텔 392곳
- **긍정/부정 리뷰 요약문** 나란히 표시
- **6개 항목 감성 점수** 막대그래프 (소음 · 가격 · 위치 · 서비스 · 청결 · 편의시설, 음수는 붉은색)
- **지도 시각화** — folium + MarkerCluster, 마커 팝업에서 구글 지도 정보·길찾기로 바로 이동
- **사이드바 Top 5** — 항목을 고르면 그 기준 상위 5개 호텔
- **원본 데이터 보기** — 선택한 범위의 표를 펼쳐서 확인

## 작동 흐름

```
지역 선택
  ↓
호텔 선택 ─── "전체 보기" → 지역 내 전 호텔을 클러스터 지도에 표시
  ↓
긍정/부정 요약 + 항목별 점수 막대그래프
  ↓
호텔 위치 지도 + 구글 지도 / 길찾기 링크
```

## 실행 방법

### 로컬

```bash
pip install -r requirements.txt
streamlit run streamlit_app_fixed.py
```

`streamlit_app_fixed.py`와 `hotel_fin_0331_1.csv`가 같은 경로에 있어야 합니다.

### GitHub Codespaces

`.devcontainer` 설정이 포함돼 있어 **저장소에서 Codespace를 열면 의존성 설치와 앱 실행이 자동으로 진행**되고 8501 포트 미리보기가 열립니다. 별도 설정이 필요 없습니다.

## 알려진 제약

- 감성 점수는 항목별로 대략 `-0.06 ~ 1.02` 범위이며, 절대 평점이 아니라 상대 비교용 지표입니다.
- `Refined_Negative`가 비어 있는 호텔이 8곳 있습니다.
- 호텔명이 중복되는 행이 2건 있어, 같은 이름의 숙소는 하나만 선택됩니다.
- 리뷰 수집·요약·점수 산출 코드는 이 저장소에 포함돼 있지 않습니다. 앱은 결과 CSV만 읽습니다.
