# Stay-View

Booking.com 리뷰를 분석해 숙소를 지도와 항목별 점수로 탐색하는 Streamlit 앱.

배포: https://stayview-11.streamlit.app/

팀 프로젝트 (2024.02 ~ 2025.04) · 권지원, 김정민, 김지민

## 기능

- 지역 → 숙소 선택 (9개 지역, 숙소 392곳)
- 긍정/부정 리뷰 요약문 표시
- 6개 항목(소음, 가격, 위치, 서비스, 청결, 편의시설) 감성점수 막대그래프
- folium 지도에 숙소 위치 표시, 구글 지도·길찾기 링크 연결
- 사이드바에서 항목별 상위 5개 숙소 확인
- 원본 데이터 표 보기


## 분석 파이프라인

앱은 아래 과정의 결과 CSV만 읽는다. 분석 코드는 이 저장소에 없다.

1. **크롤링** — Booking.com에서 후기 200개 이상인 숙소 대상, 19만 건 수집
2. **키워드 정의** — 긍정/부정 리뷰 상위 50개 단어로 감정 카테고리와 항목 키워드 구성
3. **LDA 토픽 모델링** — 리뷰를 5개 토픽으로 분류하고 6개 항목 키워드로 라벨링
4. **속성별 감성분석** — 11만 건. 한국어 약 4만 건은 KoBERT, 영어 약 7만 건은 BERT·XLM-RoBERTa. BERT+KoBERT, XLM-RoBERTa+KoBERT 앙상블로 항목별 점수 산출
5. **요약** — KoBART로 1차 요약 후 Gemini로 재정리 (`Refined_Positive`, `Refined_Negative`)
